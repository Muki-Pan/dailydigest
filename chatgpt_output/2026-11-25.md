# Story 04

* **Category:** AI Research / Creative Tech Signal · Follow-up
* **Chinese Headline:** 研究团队提出 Lyris 框架：以 3D 布局与持久记忆构建可控的长视频生成
* **English Headline:** Researchers Introduce Lyris: Layout-Guided Long Video Generation with Persistent 3D Memory
* **Chinese Summary:** 宾夕法尼亚大学与 NVIDIA 等机构的研究团队在 arXiv 提交了论文《Lyris》。该框架提出了一种结合显式 3D 点云持久记忆与 VLM 布局规划的自回归视频生成方法。系统将已观察的画面转化为 3D 点云记忆，同时由大语言模型预测未观察区域的 3D 物体包围盒，从而在单张输入图像下实现长时镜头漫游与空间视角的高度一致性。
* **English Summary:** Lyris integrates persistent 3D point cloud memory with VLM-planned bounding box layouts to enable controllable long video generation with spatial consistency.
* **Why it matters:** 这是对 AI 视频生成中空间记忆与镜头控制工作流的跟进。3D 点云持久记忆的引入，提升了生成式视频在长镜头与复杂空间移动中的渲染稳定性。
* **Editorial Signal:** AI 视频工具正在从纯文本 Prompt 引导转向显式 3D 空间结构控制，为三维空间叙事与数字场景搭建提供了新工作流。
