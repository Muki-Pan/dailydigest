## Why these stories today?

今天，我们观察到创意工具、创伤修复与地缘记忆在‘非典型空间’和‘代理技术’层面的交汇。从阿尔勒对前殖民地温室遗址的图像修复，到加州大学对身体性伤害的非煽情见证，创作者们正用温和的微观叙事重组创伤档案。同时，Comfy Org 对本地 MCP 协议的开源，预示着生成式创意工作流正式从‘画布连线’演进到‘Agent 智能代理人’时代。最后，伦敦费兹罗维亚礼拜堂的策展人驻留项目，则将创意健康、社会福祉与物理遗址深度锚定，为女性主义关护实践在实体空间中的活化提供了理想案例。

## Intro

本期简报聚焦于‘媒介修补’与‘智能代理’。在图像与身体遭遇创伤和危机的当下，艺术家与策展人正在通过细致的见证机制和非传统的物理空间，重构关于关护、记忆与主权的微观档案。而在工具层面，本地端生成式技术正在抛弃繁琐的参数操控，转向大语言模型对画布节点的深度托管，为人机协同视觉生产带来实质性的流程变革。

* **Category:** AI Research / Creative Tech Signal · New
* **Chinese Headline:** Comfy Org 开源本地端 Comfy MCP：将大语言模型 Agent 直接接入本地创意工作流
* **English Headline:** Comfy Org Open Sources Comfy MCP on Local: Seamlessly Connect LLM Agents to Local Creative Workflows
* **Chinese Summary:** Comfy Org 正式开源了本地运行的 Comfy MCP（模型上下文协议）工具。该工具允许用户将 Claude、Cursor 等任何兼容 MCP 的外部 AI 代理直接连接到本地的 ComfyUI 实例。通过该协议，Agent 能够自动读取 ComfyUI 的节点架构、检查运行模式、加载并切换模型，以及直接执行和微调参数，使用户无需手动在画布上连线，即可通过自然语言驱动复杂图像生成。
* **English Summary:** Comfy Org has open-sourced Comfy MCP, a local tool based on the Model Context Protocol. It connects LLM agents directly to ComfyUI, allowing them to construct and execute creative node workflows through text commands.
* **Why it matters:** 这表明 AI 创意工作流正从“手动连线、参数焦虑”转向“Agent 代理人协作”。本地主权与大模型上下文协议的结合，为创作者构建高自动化、自然语言导向的视觉生产管道提供了关键的底层支持。
