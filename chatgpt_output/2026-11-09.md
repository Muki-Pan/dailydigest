# Story 04

* **Category:** AI Research / Creative Tech Signal · New
* **Chinese Headline:** 研究团队发布 Cassette-Editor：专为非线性视频剪辑打造的 AI Agent 调度框架
* **English Headline:** Researchers Introduce 'Cassette-Editor' Agent Harness for Timeline-Based Video Editing
* **Chinese Summary:** 研究团队在 arXiv 上发表论文《Cassette-Editor: An Agent Harness for Editing Video the Way You Do》。该研究没有采用 Prompt 直接生成视频的做法，而是将非线性剪辑软件的时间轴文档抽象为 Agent 可调度的空间。Agent 读取时间轴结构后写入带约束的补丁，并在提交修改前进行静态规则校验。项目已在 26 分钟的真实纪录片粗剪中完成测试。
* **English Summary:** Researchers introduce Cassette-Editor, an agent harness designed for timeline-based video editing software. Instead of generating video from scratch, the system enables LLM agents to interact with non-linear editor timeline schemas via constrained patches.
* **Why it matters:** 这项研究切中了基于时间轴的真实工作流。它表明 AI Agent 正在从简单的文本对话走向对复杂软件文档与工程状态的精准操纵，对影像创作者的 Agentic 工作流设计有直接实用意义。
* **Editorial Signal:** 从 Prompt 生成走向时间轴文档架构的精准 Agent 调度
