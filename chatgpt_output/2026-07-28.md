## Why these stories today?

今日线索共同指向“日常痕迹的媒介化与可信度重构”。东京都写真美术馆将食物与家庭照料转化为社会学视觉档案；复旦大学学者提出“可追溯学术”框架，通过技术底层维护大模型时代的研究证据链；泰特现代美术馆展出修复版门迪耶塔影片，使身体在荒野中的消失与重现化为物理胶片记忆；M+博物馆将半个世纪前的电话热线重塑为香港本地方言的听觉档案；李禹焕阿尔勒基金会则面向全球征集生态与身体媒介的驻留方案。这些事件不仅在对抗遗忘，更在用具体的物质规则重建我们与日常生活的关系。

## Intro

本期编辑部聚焦“日常细节的媒介物理化”与“技术流的可信重构”。当大语言模型带来的流畅话语模糊了事实边界，我们引入了基于知识图谱与 MCP 协议的“可追溯学术”框架，它不仅是数字人文的基建，也是抵抗 AI 幻觉的实践参考。同时，从东京的家庭餐桌，到香港本地诗歌的电话热线，再到门迪耶塔在泥土里留下的身体轮廓，本期呈现的视觉和听觉线索展现了如何将日常损耗和方言记忆转化为不妥协的物质档案。

# Story 02

* **Category:** AI Research / Creative Tech Signal · New
* **Chinese Headline:** 复旦大学学者提出“可追溯学术”框架：通过页面锚点与范围契约防止 AI 时代的证据链幻觉
* **English Headline:** Fudan Researcher Proposes 'Traceable Scholarship' Framework: Combatting LLM Hallucinations with Page Anchors and Scope Contracts
* **Chinese Summary:** 复旦大学学者景德雨发表论文，针对生成式人工智能对人文学术话语的侵蚀，提出了“可追溯学术”规范框架。该研究设计了一套名为 AIH-Infra 的三层参考架构，包含文档结构化、可追溯知识库以及基于 MCP 协议（Model Context Protocol）的 Agent 网关。框架引入了“页面锚点与双页码”、“范围契约”（约束 Agent 检索范围）以及“无证据声明（NO_EVIDENCE）”（在证据不足时强制降级输出，拒绝编造）。研究团队在 29 册《康德学术版全集》知识库上成功验证了其修正检索、证据评级与评判降级的能力。
* **English Summary:** Deyu Jing from Fudan University introduces 'Traceable Scholarship,' an epistemological and technical framework designed to keep AI-assisted humanities research verifiable. Built on a three-layer architecture (AIH-Infra) and utilizing the Model Context Protocol (MCP), the system enforces page anchors and 'NO_EVIDENCE' declarations to prevent LLM hallucination.
* **Why it matters:** 该研究从“知识基础设施”的底层逻辑出发，用 MCP 协议重新设计了人文学术搜索与生产的工作流。它提出的“无证据声明”和“范围契约”对 Muki 构建个人数字图像档案馆、防止 AI 工具在分析历史影像与性别文献时出现“顺从性幻觉”具有极高的实用参考价值。
* **Editorial Signal:** 用底层的媒介协议和代码契约对抗 LLM 的流畅谎言，将“不可伪造性”重新确立为 AI 辅助人文研究的核心规范。
