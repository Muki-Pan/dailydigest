# Story 04

* **Category:** AI Research / Creative Tech Signal · Follow-up
* **Chinese Headline:** 研究团队提出 MAPE 框架：以程序演化自动化设计与优化 AI Agent 动态记忆架构
* **English Headline:** Researchers Introduce MAPE: Program Evolution for Automated Discovery of AI Agent Memory Architectures
* **Chinese Summary:** 明尼苏达大学等机构的研究团队（Xinheng Ding 等）发表论文《MAPE》，提出了一种通过自动程序演化来探索 LLM Agent 记忆架构的框架。系统采用标准化的生命周期接口与“诊断-建议”迭代循环，自动化改进记忆生成、检索与上下文准备流程。实验表明，保留原始对话历史与提取笔记相结合能防止关键细节遗失，在 LoCoMo 和 LongMemEval 基准测试上准确率提升达 12%，同时降低了 65% 的推理成本。
* **English Summary:** Researchers introduce MAPE, a program-evolution framework that automatically discovers and refines long-horizon memory architectures for LLM agents, boosting memory retrieval accuracy while reducing compute cost.
* **Why it matters:** 该研究解决了 AI Agent 在长时工作流中记忆退化和知识遗失的问题。通过把原始记录与按意图分流的证据检索分离，为构建稳定知识库和智能辅助工作流提供了实用方案。
* **Editorial Signal:** Agent 记忆设计正从依靠人工编写规则走向自动化搜索与自我优化，这一转向将提升多模态研究与长文档检索的可靠性。
